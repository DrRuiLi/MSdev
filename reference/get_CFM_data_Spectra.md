# Convert CFM Data to Spectra Object

Deprecated wrapper. Use
[`MSCC::get_CFM_data_Spectra()`](https://rdrr.io/pkg/MSCC/man/get_CFM_data_Spectra.html).

## Usage

``` r
get_CFM_data_Spectra(cfmd)
```

## Arguments

- cfmd:

  A CFM data object containing peak assignment information.

## Value

A `Spectra` object containing MS/MS spectra at three collision energy
levels.
