# Plot MS/MS spectrum for a feature

Plot experimental and reference MS/MS spectra for a given feature, with
annotation details.

## Usage

``` r
plot_MSdev_feature_spectrum(MSdev.obj, feature.id)
```

## Arguments

- MSdev.obj:

  MSdev object

- feature.id:

  Character string specifying the feature ID

## Value

ggplot object (or NULL if no spectra)
