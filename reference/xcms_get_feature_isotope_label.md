# Xcms Get Feature Isotope Label (Deprecated)

Deprecated wrapper of
[`xcms_get_feature_traced_isotopologue()`](https://drruili.github.io/MSdev/reference/xcms_extension_isotopologue.md).

## Usage

``` r
xcms_get_feature_isotope_label(xcms.xcms, iso_ele = "[13]C", ...)
```

## Arguments

- xcms.xcms:

  XCMSnExp object with isotopologue assignments.

- iso_ele:

  Isotope element string (e.g., `"[13]C"`).

- ...:

  Additional arguments.

## Value

XCMSnExp object.
