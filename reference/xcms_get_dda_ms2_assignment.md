# xcms_get_dda_ms2_assignment

match xcms scan of msLevel 2 to feature Definitions based on
precursorMz, rtime in `xcms.scan`; peakRtMin, peakRtMax, feature_id in
`featuredef`

## Usage

``` r
xcms_get_dda_ms2_assignment(xcms.xcms)
```

## Arguments

- xcms.xcms:

  xcms

- featuredef:

  featuredef

## Value

xcms
